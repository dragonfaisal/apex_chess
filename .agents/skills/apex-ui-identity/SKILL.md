# apex-ui-identity

## Trigger phrases

- UI identity
- visual polish
- theme
- copy
- premium
- Material 3
- navy
- cyan
- review screen
- dashboard
- product language

## When to use

Use for visible UI, copy, theme, navigation, loading, empty, error, archive, stats, review, import, Academy, or product identity changes.

## When NOT to use

Do not use for pure engine, classifier, backend, persistence, or workflow-doc changes with no user-facing text or visuals.

## Instructions

1. Keep Apex fast, clean, premium, and beginner-friendly.
2. Use deep dark navy as the foundation with electric blue/cyan accents.
3. Use subtle neon only when it communicates state or priority.
4. Preserve Material 3 conventions and existing shared UI components.
5. Avoid fake hype words, fake AI coaching, and unsupported opponent insights.
6. Keep review and stats surfaces dense enough for repeated use but not cluttered.
7. Check accessibility, contrast, tap targets, loading states, and empty/error copy when touched.
8. Do not redesign the visual identity unless the phase explicitly scopes it.

IDENTITY IMPACT:

COPY IMPACT:

LOADING/EMPTY/ERROR STATES:

FOCUSED VALIDATION:

SCREENSHOT OR MANUAL CHECK TRIGGER:
